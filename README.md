# Site du Centre pédiatrique Le Saule

Hébergement **temporaire** sur GitHub Pages, le temps que GoHighLevel libère
le nom d'hôte `cplesaule.ca` de sa configuration Cloudflare for SaaS.

Le dépôt de travail (sources, gabarit, script de construction) reste privé.
Ici il n'y a que le résultat de `python build.py`, c'est-à-dire le site public.

Une fois GHL débloqué, le site repasse sur Cloudflare Workers et ce dépôt
peut être supprimé.
